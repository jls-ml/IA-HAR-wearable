# IA-HAR-wearable

Wearable device project for Human Activity Recognition using Artificial Intelligence.

## Description

This project focuses on developing a wearable device capable of recognizing human activities using machine learning and artificial intelligence techniques.

## Project Structure

- **hardware/** - KiCad schematics and PCB designs
- **firmware/** - Embedded software for the wearable device
- **software/** - Data processing and AI models

## Getting Started

### Prerequisites

- KiCad (for viewing and editing schematics/PCB)
- Python 3.8+
- Required Python packages (see requirements.txt)

### Installation

```bash
# Clone the repository
git clone https://github.com/jls-ml/IA-HAR-wearable.git
cd IA-HAR-wearable

# Install dependencies
pip install -r requirements.txt
```

## Hardware

The hardware designs are located in the `hardware/` directory and include:
- Schematic files (.sch, .kicad_sch)
- PCB layouts (.kicad_pcb)
- Component libraries and footprints
